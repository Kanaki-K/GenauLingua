### Что делать, когда пакеты вернутся

Порядок важен, он выведен из ошибок:

```bash
# 1. Проверить предложения ДО применения — бесплатно
python -m app.scripts.validate_translations --files final_0.jsonl final_1.jsonl final_2.jsonl final_3.jsonl

# 2. Применить
python -m app.scripts.retranslate_wordbase apply --file final_0.jsonl   # и остальные

# 3. Бесплатные правки, которые прогон ломает каждый раз
python -m app.scripts.fix_turkish_i --apply
python -m app.scripts.fix_uk_apostrophe --apply

# 4. Примеры ИЗ ДВУХ источников: пересечение мало, один пропускает половину
python -m app.scripts.example_quality --out defects.jsonl
python -m app.scripts.merge_defects --detector defects.jsonl \
    --model final_0_bad_examples.jsonl --out merged.jsonl
python -m app.scripts.fix_examples propose --in merged.jsonl   # ЕДИНСТВЕННЫЙ платный шаг
python -m app.scripts.fix_examples apply --file example_fixes.jsonl

# 5. Группы, озвучка, уборка
python -m app.scripts.rebuild_word_groups
python -m app.scripts.tts_synthesize
python -m app.scripts.tts_prune_orphans --delete
```

Всю последовательность исполняет `app/scripts/finish_translation_round.py`.

После пересборки групп **обязательно** сверить прогресс — он не должен
измениться ни на единицу:

```sql
SELECT SUM(times_shown), SUM(times_correct) FROM user_words;
-- ожидается 29691 и 26110
```

`obtain_audio`, а массовый синтез писал клип как есть — и каждый пересинтез
возвращал тишину. У польского было не обрезано 65% клипов.

**Флаг `--keep-cache` после настоящей обрезки передавать нельзя** — сохранённые
`file_id` ведут на прежнее аудио в Telegram.

## Чему я научился на своих ошибках

Записано, потому что каждый пункт стоил денег или времени.

**Проверка, которая врёт, опаснее отсутствия проверки.** Поймал себя семь раз:
проверка искала не в том ключе и молча пропускала всё; браковала `znajdować się`
и `teslim etmek`; считала турецкий аблатив `-den` немецким артиклем; видела
немецкий артикль в английском `to die of hunger`; ругалась на `DVD` в русской
колонке; объявляла дефектом 1704 исправных клипа; дважды приезжала с символом
backspace вместо `\b` после правки через оболочку. Поэтому: смотреть на вывод, а
не на число, и ставить скриптам самопроверку.

**Отменённый пакет не значит пустой.** Запросы, уже начатые, доводятся до конца
и списываются. Так нашлись 50 оплаченных результатов, которые я считал
потерянными.

**Устаревшие предложения затирают исправленное.** Из 1335 восстановленных 1142
оказались старше базы. Перед применением сверять, есть ли дефект сейчас.

**Порция в 20 слов упирается в предел вывода** и теряет слова молча. На сложных
записях ставить `--chunk 6`.

**Строковые правки — редактором, не через оболочку.** Экранирование `\b` ломалось
трижды.
