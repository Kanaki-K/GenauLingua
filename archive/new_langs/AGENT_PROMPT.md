# Задание агенту-переводчику

Ты переводишь немецкий словарь Telegram-бота GenauLingua на итальянский,
испанский, французский и чешский. Проект: C:/Users/lodk9/PycharmProjects/GenauLingua
(Windows, Git Bash). Номера твоих блоков — в сообщении, делай их по очереди.

1. Прочитай правила целиком: archive/new_langs/GUIDE.md — они обязательны.
   Образец стиля — первые 15 строк archive/new_langs/out/block_0000.jsonl.
2. Для каждого блока NNNN: вход archive/new_langs/in/block_NNNN.tsv (поля
   через TAB: id, de, art, pos, lvl, ex_de, en, ex_en, ru, uk, pl, tr).
   Переводи САМ, своими знаниями языков — никаких API и внешних сервисов.
   Качество важнее скорости: бытовой живой язык, первое значение — то, что
   скажет носитель; пример — точный перевод немецкого примера (ex_de) и
   содержит само слово. Готовые ru/uk/en/pl/tr — подсказка о значении, не
   образец: сверяйся с немецким.
3. Запиши archive/new_langs/out/block_NNNN.jsonl — те же id в том же
   порядке, ключи: id, de, it, ex_it, es, ex_es, fr, ex_fr, cs, ex_cs
   (+ note только при надобности). Пиши Python-скриптом в СВОЕЙ подпапке scratchpad
   (назови её по номерам блоков, напр. b0025/ — scratchpad общий с другими
   агентами, чужие файлы не трогать) через json.dumps(ensure_ascii=False). Можно в 2–4 приёма (дописывая),
   итог — один файл на блок. Скрипт с данными создавай инструментом Write,
   а не heredoc в Bash: апострофы (l'uomo, j'ai) ломают heredoc.
4. Проверка:
   PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -m app.scripts.new_langs_check archive/new_langs/out/block_NNNN.jsonl
   «ОШИБКА» — исправить до нуля; каждое «проверить» посмотреть глазами
   (неправильные глаголы, падежи местоимений, глагол с предлогом — ложные;
   настоящий изъян — исправить).
5. Второй проход на смысл: перечитай каждый ряд — немецкий пример рядом с
   четырьмя твоими. Та же фраза, те же лица и время? Вежливость как в
   оригинале (du→tu/tú/tu/ty, Sie→Lei/usted/vous/vy)? Первое значение
   нейтральное и бытовое? Диакритика? Артикль у существительных it/es/fr?
   Исправь и прогони проверку снова.
6. Меняешь ТОЛЬКО свои файлы out/block_NNNN.jsonl. В базу не пиши, git не
   трогай, другие файлы не правь. Переводы ru/uk/en/pl/tr утверждены и на
   проде — НЕ исправляй их; явную ошибку в них только упомяни в ответе.

Ответ — коротко, по-русски: по каждому блоку число рядов и итог проверки;
сколько исправил на втором проходе; 2–3 трудных случая; ошибки в старых
языках, если заметил; замечания к GUIDE.md, если есть.
