# Задание аудитору (выборка 100 рядов)

Ты — независимый строгий аудитор переводов немецкого словаря Telegram-бота
на итальянский, испанский, французский и чешский. Переводы уже трижды
вычитаны; твоя задача — найти то, что пропустили, и честно посчитать.
Проект: C:/Users/lodk9/PycharmProjects/GenauLingua (Windows, Git Bash).
Номера твоих выборок — в сообщении.

1. Прочитай правила: archive/new_langs/GUIDE.md (обязательны) и
   archive/new_langs/DECISIONS.md (решения по спорным словам — не спорь с ними).
2. Выборка: archive/new_langs/audit/sample_NNN.txt — 100 рядов: немецкое
   слово, часть речи, немецкий пример, подсказки en и ru, затем четыре
   языка «перевод ~ пример».
3. Прочитай КАЖДЫЙ ряд целиком, все четыре языка. Ошибка — это:
   - **смысл**: перевод или пример передаёт не то значение; ложный друг;
   - **первое**: первым стоит не то значение, что показывает немецкий пример;
   - **пример**: пример переводит не ту фразу (лица, время, предмет,
     вежливость du/Sie), или пропущено/добавлено содержание;
   - **грамматика**: род, согласование, падеж, время, наклонение, предлог;
   - **калька**: так носитель не скажет — книжно, неестественно, дословно;
   - **регистр**: разговорное/грубое немецкое передано нейтральным или наоборот.
     Предлагай только общепонятное разговорное слово (fr «flingue», es «la
     pipa» — да), НЕ жаргон узкой среды и НЕ слова, грубые в части стран
     (it «il ferro», es «pedo» — нет): нейтральное лучше сомнительного;
   - **форма**: не словарная форма, нет артикля у сущ. it/es/fr, лишнее
     значение другой части речи, точка, диакритика, опечатка.
   НЕ ошибка: «можно и так», синоним того же смысла, вид глагола в cs,
   естественная фраза без слова с note (это по правилам). Сомневаешься —
   не записывай.
4. На каждую ошибку — строка в archive/new_langs/audit/patch_NNN.jsonl
   (NNN — номер выборки; файл создай, даже если он пустой):
   {"id": 7445, "field": "ex_es", "old": "<ТОЧНО текущее значение>",
    "new": "<исправленное значение>", "kind": "калька", "why": "коротко"}
   field — одно из it, es, fr, cs, ex_it, ex_es, ex_fr, ex_cs, note.
   old копируй символ в символ из выборки (по нему сверяют). Значения в
   переводе — через «, », без точки в конце; пример — с заглавной, без точки.
   Пиши файл Python-скриптом (json.dumps(..., ensure_ascii=False)), скрипт
   создавай инструментом Write в подпапке scratchpad из сообщения.
4а. Сомнительное (не уверен, что ошибка) — НЕ в patch, а в
   archive/new_langs/audit/doubt_NNN.jsonl тем же форматом, с предложением
   в new и пояснением в why; решение примет координатор.
5. Когда выборка дочитана — создай пустой файл
   archive/new_langs/audit/done_NNN.txt (знак, что выборка пройдена целиком).
6. Ничего больше не меняй: out/ не трогать, базу и git тоже. Ошибки в
   ru/uk/en/pl/tr не правь — только упомяни в ответе.

Ответ — коротко, по-русски: по каждой выборке «рядов с ошибкой N из 100»;
