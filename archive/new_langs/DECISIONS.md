# Решения по словам, переведённым в нескольких блоках

Кто выравнивает слово между блоками — сначала смотрит сюда. Если слово тут
есть, делает так, как записано (не переписывает обратно). Если нет — решает
и ДОПИСЫВАЕТ строку: слово (pos) — что первым по языкам — кто/блок.

- einfach (ADJ) — первым «semplice / sencillo / simple / jednoduchý» — v0000
- darüber (ADV) — первым «ne / … / en / …» (как в примере) — v0000
- treffen (VERB, sich treffen) — es «quedar» первым, fr «se retrouver» первым — v0000
- erinnern (VERB) — it «ricordare, ricordarsi», es «recordar, acordarse», fr «rappeler, se souvenir, se rappeler», cs «připomenout/připomínat, …, vzpomínat si» (вид первым — как в примере ряда); «pamatovat si» не перевод — v0006
- erschrecken (VERB) — fr первым «faire peur» (бытовое; так в примере «Tu m'as fait peur»), далее «effrayer» — v0013
- Prozent (NOUN) — it «per cento», es «por ciento», fr «pour cent» без артикля + note, вторым «la percentuale / el porcentaje / le pourcentage» — v0013
- räumen (VERB, «Sie räumt das Zimmer») — значение «освободить/вынести» (без auf — не «прибрать»): «sgomberare / vaciar / vider / vyklidit» первым; en/ru «tidying/убирать» неточны — v0017
- Internet (NOUN) — it/es/fr «internet» без артикля + note — v0017
- verkaufen (VERB) — cs «prodat, prodávat» (как в 0006) — v0017
- bestehen (VERB) — cs «trvat na» (не голое «trvat») — v0017
- bestehen (VERB) — разные значения законны: «Prüfung bestehen» → «superare / aprobar / réussir / složit»; «bestehen aus» → «essere composto / constar de / se composer / skládat se» первым (п.19); cs «složit» добавлено и в ряд «состоять» — v0021/0024
- erschrecken (VERB) fr — по решению v0013: «faire peur, effrayer, s'effrayer» («sursauter» убрано) — v0021/0024
- trauern (VERB) — fr первым «être en deuil», затем «pleurer» (как it/es и блок 0095); пример может быть с «pleurer» — v0041
- engagiert (ADJ) — fr «investi» первым, cs «zapálený» первым (так в примерах и 0027, и 0083); it «impegnato», es «comprometido» — v0025
- gemeinsam (ADJ, «gemeinsame Interessen») — первым «in comune / en común / en commun / společný»; наречное «gemeinsam essen» (id 322) — «insieme / juntos / ensemble / společně» — v0025
- genau (ADJ 7013 «die genaue Adresse») — первым прилагательное «esatto / exacto / exact / přesný», наречие вторым; ADV 325 — наречие первым (п.19); mies 6772/7160 — порядок по примеру ряда (погода / подлость), не выравнивать — v0029
- vermitteln (VERB) — по п.19 первым значение примера: «Wohnungen vermitteln» → «procurare / conseguir / trouver / zprostředkovat» (2046), «zwischen Parteien» → «mediare / mediar / servir de médiateur» (14118) — v0045
- hell (ADJ), erheben (VERB) — первым значение примера ряда: цвет → «chiaro / claro»; «Gebühr erheben» → «riscuotere / recaudar / percevoir / vybírat» — v0045
- wirklich (ADJ, «der wirkliche Grund») — только прилагательные «vero, reale / verdadero, real / vrai, réel / skutečný, opravdový»; наречие (2104) — «davvero…»; scheinen/merken — первым значение из примера ряда (7080 «sembrare», 10475 «ricordare/retenir») — v0033
- mies (ADJ) — пример про поступок («miese Tour»): первым «meschino / rastrero / minable / podlý»; про погоду (0030) — «schifoso / asqueroso / pourri / mizerný» (п.19) — v0037
- rühren (VERB) — пример «gerührt» (растроган): первым «commuovere / conmover / émouvoir / dojmout»; про размешивание (11687) — «mescolare / remover / remuer / míchat» (п.19) — v0037
- Kompromiss (NOUN) — es первым «el acuerdo», вторым «el compromiso» (compromiso в быту — обязательство) — v0053
- anstrengen (VERB) — как в 0051: it «affaticare, stancare, sforzarsi», es «cansar, agotar, esforzarse», cs «namáhat, unavovat, snažit se»; fr в 7668 оставлено «fatiguer, faire un effort, s'efforcer» — v0065
- treten (VERB) — первым значение примера ряда: «gegen die Tür treten» (7843) → «dare un calcio / dar una patada / donner un coup de pied / kopnout»; «auf den Fuß treten» (6413) → «pestare / pisar / marcher sur / šlápnout» (п.19), не выравнивать — v0073
- zurückbekommen (VERB) cs — «dostat zpátky, získat zpět» (как в 0049) — v0061
- beruflich (ADJ) — по п.19 порядок по примеру ряда: «beruflich reisen» (97) — «per lavoro / por trabajo / pour le travail / pracovně» первым; «berufliche Entwicklung» (9157) — «professionale / profesional / professionnel / profesní» первым — v0089
- hunderttausend (OTHER) — 13583 «hunderttausend Plätze» → «centomila / cien mil / cent mille / sto tisíc»; 8075 «Hunderttausende» → первым «centinaia di migliaia / cientos de miles / des centaines de milliers / statisíce» (п.19) — v0085
- hören (VERB) — пример «zuhören» (14274): первым «ascoltare / escuchar / écouter / poslouchat»; иначе (421) «sentire / oír / entendre / slyšet»; erhaben 8321 «das Erhabene» — первым «sublime», 11241 (мысли) — «elevato…» (п.19) — v0097
- vorzeitig (ADJ 8575 «vorzeitige Pensionierung») — только прилагательные «anticipato, prematuro / anticipado, prematuro / anticipé, prématuré / předčasný»; наречное употребление (18832) с наречиями не трогать (п.19) — v0109
- Galle (13101, «voller Galle») — переносное значение первым: «il fiele / la hiel / le fiel», затем bile/bilis/bile (п.19) — v0109
- schrumpfen, bezwingen, abgeben, heimsuchen (VERB) — первым значение примера ряда (п.19), не выравнивать: экономика 8347 → «contrarsi / contraerse / se contracter», свитер 8193 → «restringersi / encogerse / rétrécir / srazit se»; гора 8367 → «conquistare / conquistar / zdolat», страх 10885 → «vincere / vencer»; «Stellungnahme abgeben» 8348 → «rilasciare / emitir / donner / vydat», «Hausaufgaben» 1100 → «consegnare / entregar / rendre / odevzdat»; кошмары 8365 → «perseguitare / atormentar / hanter / pronásledovat» — v0101
- Ehepartner (NOUN) — как в 0122: «il coniuge, il marito, la moglie / el cónyuge, el marido, la esposa / le conjoint, l'époux / manželský partner, manžel, manželka»; bestimmt (ADV) — как в 0122 — v0117
- Bankkarte, Girocard (NOUN) it — первым «il bancomat» (так говорят о карте: «Pago con il bancomat»), вторым «la carta di debito» — v0121
- früh (ADJ 18941 «ein frühes Aufstehen») — прилагательные первыми: it «precoce, presto» (пример с presto + note), es «temprano», fr «matinal, précoce», cs «časný, brzký»; наречие 294 — «presto / temprano / tôt / brzy» (п.19) — v0113
- Käufer (NOUN) cs — первым «kupující» (как 9771), «kupec» вторым; Esser es — «el comilón» («el comedor» = столовая), пример «Soy muy comilón» — v0125
- по п.19 первым значение примера ряда (в других блоках не выравнивать): Hals «gola/garganta/gorge» (боль в горле); allerdings «in effetti / desde luego / en effet» (подтверждение); davor «ne / de eso / en / toho» (как darüber); reichen «passare / pasar / passer / podat» (соль); fassen «capacitarsi / comprender / concevoir / pochopit»; nah(e) «cerca / près / blízko»; laut «forte / alto» (громче); selbstverständlich «ovvio / obvio / évident / samozřejmý»; dunkel it «buio» (темнеет); wählen «eleggere / élire / volit» (президент); behandeln «curare / soigner» (врач); Alarm «la sveglia / budík»; probieren «assaggiare / goûter / ochutnat»; anziehen (sich) «vestirsi / vestirse / s'habiller / obléknout se»; wild «scatenato / revoltoso / agité» (дети); Geburt «il parto / el parto / l'accouchement / porod»; trennen (Müll) fr «trier», cs «třídit»; Untersuchung es «la revisión», fr «la visite médicale»; schwer «difficile / difícil / difficile» (задача); ergeben «dimostrare / mostrar / montrer» (покажет); fein «squisito / exquisito / excellent / výborný» (еда); komplett «completamente / complètement / úplně» (нареч.) — t0008 (0008–0015)
- treffen (VERB, «wir treffen uns») cs — «sejít se» первым (как es «quedar», fr «se retrouver»), it «incontrare, incontrarsi» оставлено — v0000/третий круг
- sie (839, «Sie kommen» — они), Stelle («eine Stelle suchen» — работа), Wahl («die Wahl ist am Sonntag» — выборы), schießen («ein Tor schießen»), erreichen («dich erreichen» — связаться), ewig («dauert ewig» — целую вечность) — первым значение примера ряда (п.19); в рядах с другим примером не выравнивать — v0000/третий круг
- unverschämt (ADJ, «unverschämte Lüge») — как в 11601: «spudorato / descarado / éhonté / nehorázný» первым; anfahren 17149 (грузовик и машина) — es «chocar contra» первым, 2175 (сбил человека) — «atropellar»; не выравнивать (п.19) — v0040
- leicht 6826 («leichte Übung» — лёгкий=простой) — первым «facile / fácil / facile», 6292 (сумка) — «leggero / ligero / léger»; geschäftlich 8829 («geschäftlich in Berlin») — es «por trabajo» первым (как beruflich), 17823 — «de negocios»; leihen 9774 («das Buch geliehen» — взял) — «prendere in prestito / pedir prestado / emprunter / půjčit si» первым, 1651 (дать) — «prestare / prestar / prêter / půjčit»; не выравнивать (п.19) — v0024/третий круг
- locker, knapp, lenken, jährlich — первым значение примера ряда (п.19), не выравнивать: locker 7706 «lockerer Umgang» → «disinvolto / relajado / décontracté», 10182 (винт) → «allentato / flojo / desserré»; knapp 7718 (время) → es «justo», fr «serré», 6528 (деньги) → «escaso / rare»; lenk 14152 (разговор) → «dirigere / llevar / orienter / stočit», lenken 2658 (машина) → «guidare / conducir / conduire / řídit»; jährlich 1567 «findet jährlich statt» → «ogni anno / cada año / chaque année / každý rok», 18870 (прил.) → «annuale…»; grob 7629 it — «grossolano» первым, как 7005 — v0064
- Macht (16293 «die europäischen Mächte»), Kreislauf (15558 «Kreislauf der Natur»), reiben (7324 «Karotten reiben»), Zulassung (16328 авто) — первым значение примера ряда (п.19): «la potenza / la potencia / la puissance / velmoc», «il ciclo / el ciclo / le cycle / koloběh», «grattugiare / rallar / râper / strouhat», «il libretto di circolazione / el permiso de circulación / la carte grise / technický průkaz»; в других блоках не выравнивать — t0048
- froh (ADJ) — «Frohe Weihnachten» (10255): первым «felice / feliz / joyeux / veselý» (п.19); «Ich bin froh» (293) — «contento / contento / content / rád», не выравнивать; eng (ADJ) — списки во всех трёх рядах одинаковы («stretto / estrecho / étroit / úzký» первым), примеры подогнаны под первое значение; treffen cs — «sejít se, potkat, zasáhnout» и в 14982 (как в 941) — t0016
- rau, fies, eng, giftig — rau 7853 «der raue Ton» → первым «aspro / áspero / rude / drsný», 8240 (голос) → «rauco / rauque» (п.19); fies 11102 «fieser Trick» → «meschino / mezquino / vache / podlý» первым, 10528 (комментарий) — «cattivo / feo / méchant»; eng 7792 (обувь) и giftig 12877 (грибы) — список как в 222/2528, правлены примеры (fr «trop étroites», cs «úzké», fr «toxiques»); не выравнивать — t0072
- Verständnis («Ich habe Verständnis dafür») — пример it/es/fr глаголом: «Lo capisco benissimo / Lo entiendo perfectamente / Je le comprends très bien» + note; кальку с существительным НЕ возвращать — я (координатор)
- kriegen (8107 «Pässe zurückkriegen») fr — первым «récupérer» (так в примере), 6261 «Hunger kriegen» не выравнивать; vornehm (8162 «vornehme Familie») — it «nobile», cs «urozený» первым, 10970 (ресторан) — «elegante…» (п.19) — t0088/третий круг
- liebevoll (ADJ) it — «affettuoso, amorevole», пример с «affettuosamente» (как 10734 в 0053); nah 8019 — как 1717: «cerca / près / blízko» первым (наречие в примере) — t0080
- mild (ADJ) — по п.19 порядок по примеру ряда: учитель (10809) — «indulgente / indulgente / indulgent / shovívavý» первым; погода (8246) — «mite / suave / doux / mírný» — t0056
- Glückwunsch (NOUN) fr — как в 0008: «les vœux, les félicitations» (14112 выровнен) — t0056
- erwidern (VERB, «seinen Blick erwidern», 14098) — первым «ricambiare / devolver / rendre / opětovat», «ответить» вторым (п.19) — t0056
- Kuli (9276, пример про носильщика), widerwillig (11566, «stimmte widerwillig zu»), vorweisen (8661, «Erfolge vorweisen»), Peinlichkeit (11575, случай), unerkannt (8648) — первым значение примера ряда (п.19): «il facchino / el culí / le coolie / nosič», «controvoglia / a regañadientes / à contrecœur», it «vantare», cs «prokázat», it «la figuraccia», fr «la situation embarrassante», «in incognito / de incógnito»; Gesandte 16936 = 16987 («l'inviato, l'emissario», cs «vyslanec»); Freund/in, Arzt/Ärztin — мужская форма первой, хоть пример и в женском; it «il capo», fr «le médecin» — одна форма на оба рода — t0112
- individuell (ADJ 2574 «Jeder Mensch ist individuell») — первым «unico / único / unique» (п.19), cs «individuální» оставлено; separat (ADJ 1863, наречный пример «separat berechnet») — первым «a parte / aparte / séparément / zvlášť», как gesondert 1481; X/in: обе формы подряд, мужская первой (Partner, Gastarbeiter, Geschäftsführer, Handwerker, Musiklehrer, Einbrecher); общие для обоих родов (l'automobilista, il giudice, le juge, pokladní, vedoucí) — одной формой — t0120
