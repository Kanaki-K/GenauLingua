Владелец (патч 2.1, после отзыва «убрать сленг типа бабки»): в словаре бота

грубое. Разговорное и грубое — вторым, с пометкой в скобках:
it «(colloq.)» / «(volg.)», es «(coloq.)» / «(vulg.)», fr «(fam.)» / «(vulg.)»,
cs «(hovor.)» / «(vulg.)». **Примеры — нейтральной речью**, без сленга и мата.
