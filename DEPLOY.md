# Заливка на прод

Порядок важен. Каждый шаг проверяемый, и после каждого понятно, можно ли
двигаться дальше или надо откатываться.

На проде 204 человека и три месяца прогресса. Всё, что здесь описано,
проверено на копии этих данных, но проверено — не значит «можно не делать
бэкап».

---

## 0. Перед началом

**Бэкап базы. Без него дальше не идти.**

```bash
# На сервере
docker compose exec -T postgres sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' \
  | gzip > ~/backup-$(date +%F-%H%M).sql.gz
ls -lh ~/backup-*.sql.gz        # убедиться, что файл не пустой
```

Проверить, что бэкап читается:

```bash
gunzip -c ~/backup-*.sql.gz | head -30
```

**Записать текущую версию схемы** — с неё откатываться:

```bash
docker compose exec app alembic current
```

## 1. Что меняется в базе

Шесть миграций. Все обратимы, round-trip проверен.

| Ревизия | Что делает | Опасность |
|---|---|---|
| `d7e8f9a0b1c2` | многоязычное обучение: языки у пользователя, язык в прогрессе, группы слов | переносит прогресс на канонические слова |
| `e8f9a0b1c2d3` | `answered_questions` в сессиях | безопасно, только добавление |
| `f9a0b1c2d3e4` | колонки польского | безопасно, пустые колонки |
| `a0b1c2d3e4f5` | таблица `word_audio` | безопасно, новая таблица |
| `d3e4f5a6b7c8` | настройки озвучки | `audio_enabled` включается всем |
| `e4f5a6b7c8d9` | вид репорта: текст или озвучка | меняет уникальный ключ |
| `f5a6b7c8d9e0` | `bot_id` у клипа озвучки | безопасно |

Самая существенная — первая: она перепривязывает прогресс пользователей на
канонические слова и схлопывает дубли. На копии прода это 21 265 записей
прогресса, ни одна не потеряна: счётчики суммируются, «выучено» берётся по
логическому ИЛИ.

`audio_enabled` включается **всем существующим пользователям**. Это
намеренно: озвучку просили в отзывах, и патч без неё был бы невидим. Кому
мешает — выключит в настройках.

## 2. Заливка

```bash
# На сервере
cd /path/to/GenauLingua
git fetch origin
git checkout feature/multilang-learning
git pull

docker compose build app
docker compose up -d app        # alembic upgrade head идёт при старте
docker compose logs -f app      # смотреть до строки «Планировщик запущен»
```

В логах должно быть:

```
🗄️  База на связи: ...
📦 Routers loaded: ... ✅ admin.py
⏰ Планировщик запущен, работ: N
```

Если миграции упали — бот не начнёт опрос Telegram, а напишет причину.
Это специально: лучше не подняться, чем падать на каждом нажатии.

## 3. Сразу после заливки

**Пересобрать группы слов.** Обязательно: викторина отбирает слова по ним.

```bash
docker compose exec app python -m app.scripts.rebuild_word_groups
```

**Проверить, что викторина запускается.** Открыть бота, нажать «Учить слова»,
ответить на вопрос, дойти до разбора. Если звука нет — это не поломка,
см. шаг 4.

**Проверить сквозные сценарии машинно:**

```bash
docker compose exec app python -m app.scripts.verify_all_flows
```

Ожидается 82 шага и ни одной проблемы.

## 4. Озвучка: два шага, и они раздельные

Озвучка не нужна для работы бота. Он работает и без неё — карточка выходит
текстовой. Поэтому эти шаги можно делать после заливки, не спеша.

### 4.1. Перенести синтезированные клипы

Синтез уже сделан локально: все слова и все примеры по всем языкам,
около 2,3 ГБ. Копируется как есть:

```bash
# С машины разработчика
rsync -avz --progress tts/ user@server:/path/to/GenauLingua/tts/
```

Отдельно монтировать не нужно: в `docker-compose.yml` каталог проекта
смонтирован в контейнер целиком (`- .:/app`), поэтому `tts/` рядом с кодом
контейнер видит сразу.

Проверить, что доехало:

```bash
docker compose exec app python -m app.scripts.tts_synthesize --stats
```

### 4.2. Загрузить в Telegram и получить file_id

**Этот шаг обязательно боевым ботом.** `file_id` принадлежит конкретному
боту, и клипы, загруженные тестовым, боевой отправить не сможет.

```bash
docker compose exec app python -m app.scripts.tts_pregenerate \
  --lang de --all --delete-after
```

`--delete-after` отправляет клипы в чат админа и сразу удаляет: `file_id`
после удаления сообщения остаётся рабочим. Уведомления отключены, сообщения
живут меньше секунды. Около 2,5 часа на язык при темпе 3 клипа в секунду.

Прогон прерываемый: уже загруженное не переделывается. Можно гнать языки по
одному в удобное время.

**Без этого шага тоже работает.** Клип загрузится при первом показе слова:
первый человек ждёт лишнюю секунду, все следующие получают мгновенно.
Предгенерация только убирает эту секунду.

## 5. Если что-то пошло не так

### Откат кода без отката базы

Новые колонки старому коду не мешают — он их просто не видит. Поэтому
сначала пробовать так:

```bash
git checkout main
docker compose build app && docker compose up -d app
```

Исключение: `user_words` получил язык в первичном ключе, и старый код о нём
не знает. Если викторина после такого отката ведёт себя странно — откатывать
и базу.

### Откат базы

```bash
docker compose exec app alembic downgrade <ревизия из шага 0>
```

Внимание: откат `d7e8f9a0b1c2` **не восстановит** разделение прогресса,
схлопнутое при схлопывании дублей. Для полного возврата — восстановление
из бэкапа:

```bash
gunzip -c ~/backup-....sql.gz | docker compose exec -T postgres \
  sh -c 'psql -U "$POSTGRES_USER" "$POSTGRES_DB"'
```

### Озвучка не играет

Проверить по порядку:

```bash
# Клипы на диске есть?
docker compose exec app python -m app.scripts.tts_synthesize --stats

# Что в кэше file_id и чьи они?
docker compose exec -T postgres sh -c \
  'psql -U "$POSTGRES_USER" "$POSTGRES_DB" \
   -c "SELECT bot_id, COUNT(*) FROM word_audio GROUP BY bot_id;"'
```

Если `bot_id` не совпадает с id боевого бота (цифры до двоеточия в токене) —
это клипы другого бота, они не заиграют. Бот сам их переделает при показе,
но можно и почистить:

```sql
DELETE FROM word_audio WHERE bot_id IS DISTINCT FROM <id боевого бота>;
```

## 6. Что проверить на следующий день

- `/admin` → репорты: появились ли жалобы на произношение. Это лучший
  источник того, чего машинная проверка не ловит — ударения и слов с двумя
  чтениями.
- `/admin` → аналитика: точность должна быть около 88%, а не 60%. Прежняя
  цифра считалась от запланированных вопросов, а не от отвеченных.
- Сколько людей переключили изучаемый язык и сколько выключили озвучку.

## Чего в этой заливке нет

- **Польский как язык изучения.** Колонки добавлены, но пустые: переводы
  генерируются отдельным прогоном. Пока они пусты, польский не входит в
  список доступных языков — иначе викторина не нашла бы ни одного слова.
- **Исправленные переводы.** Прогон по базе идёт отдельно и в прод не
  попадает автоматически: скрипт пишет предложения в файл, применяются они
  вручную командой `apply`.
