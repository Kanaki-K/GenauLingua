# Заливка на прод

Порядок важен. Каждый шаг проверяемый, и после каждого понятно, можно ли
двигаться дальше или надо откатываться.

На проде 204 человека и три месяца прогресса. Всё, что здесь описано,
проверено на копии этих данных, но проверено — не значит «можно не делать
бэкап».

---

## 0. Перед началом

**Бэкап базы. Без него дальше не идти.**

```bash
# На сервере
docker compose exec -T postgres sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' \
  | gzip > ~/backup-$(date +%F-%H%M).sql.gz
ls -lh ~/backup-*.sql.gz        # убедиться, что файл не пустой
```

Проверить, что бэкап читается:

```bash
gunzip -c ~/backup-*.sql.gz | head -30
```

**Записать текущую версию схемы** — с неё откатываться:

```bash
docker compose exec app alembic current
```

## 1a. Что меняется в словарной базе

Переводы и примеры правились отдельными прогонами, и в прод они попадают
**не с кодом, а с данными**. Выбор здесь: везти исправленную базу или
оставить нынешнюю.

Что сделано на dev-копии:
  - **переводы A1 и A2** пересобраны: 3022 слова. Многозначные слова получили
    все значения, а не одно — это то, что прод-аналитика показывала как
    главную проблему качества (точность 71% против 80% на таких словах);
  - **польский заполнен** на A1 и A2: 2832 канонических слова. На B1 и выше
    только те слова, которые попали в отдельные правки, поэтому польский пока
    НЕ открыт как язык изучения;
  - **примеры переписаны** по всем уровням — те, в которых не было самого
    слова. Дефектов было 3,67%, осталось 0,22%. Выборка из 16 остатков не
    содержит настоящих: это словоизменение, которого отсев по началу основы
    не видит («брать» → «возьму», «ağız» → «Ağzım»);
  - **турецкая İ**: 429 строк. Прогон переводов ставил латинскую «I» там, где
    нужна «İ», а это разные буквы — озвучка произносила такие слова неверно.
    23 слова с настоящей «ı» («ışık», «ıslak», «ızgara») сохранены;
  - **71 запись с испорченным переводом**: перевод не в словарной форме
    («смотрели» вместо «смотреть»), перевод не на том языке (украинские
    «Ігуменя», «Шваґер» в русской колонке), выдуманные слова («Стабо́рт»
    вместо «штирборт», турецкое «Baltalaştırmak» вместо «baltalamak»);
  - **15 правок разметки**: существительные со строчной, артикль у наречия и
    прилагательного, часть речи OTHER у существительных;
  - **14 слов вернулись на свой уровень**: одно и то же немецкое слово лежит
    в базе на двух уровнях, и канонической становилась старшая запись —
    «Taxifahrer» есть на A1, а видели его только на B2.

Способ переноса — обычный дамп таблицы `words` с dev на прод. Прогресс
пользователей от этого не страдает: он привязан к id слов, а id не менялись.
После переноса **обязательно** пересобрать группы слов (шаг 3).

### Порядок шагов после любого прогона переводов

Порядок важен, и он выведен из ошибок, а не придуман. Каждый шаг закрывает то,
что предыдущий за собой оставляет.

```bash
# 1. Если пакет прерван — забрать его, прежде чем платить за повторный прогон.
#    Отменённый пакет не значит пустой: начатые запросы доводятся до конца и
#    списываются. Так нашлись 50 оплаченных результатов, считавшихся потерянными
python -m app.scripts.collect_batch --list
python -m app.scripts.collect_batch msgbatch_... --kind words

# 2. Применить переводы
python -m app.scripts.retranslate_wordbase apply --file <предложения>.jsonl

# 3. Турецкая İ: прогон ставит латинскую «I» систематически
python -m app.scripts.fix_turkish_i --review
python -m app.scripts.fix_turkish_i --apply

# 4. Примеры — ОБА источника. Отсев по основе и пометки модели ловят разное:
#    на 719 парах пересечение было 13, то есть один источник пропускает половину
python -m app.scripts.example_quality --out defects.jsonl
python -m app.scripts.merge_defects --detector defects.jsonl \
    --model <прогон>_bad_examples.jsonl --out defects_merged.jsonl
python -m app.scripts.fix_examples propose --in defects_merged.jsonl
python -m app.scripts.fix_examples apply --file example_fixes.jsonl

# 5. Записи, которые fix_examples отклонил, — это испорченные ПЕРЕВОДЫ, а не
#    примеры. Их надо пересобрать переводом, а не правкой примера
python -m app.scripts.retranslate_wordbase propose --ids <id из *_rejected.jsonl>

# 6. Группы: переводы входят в ключ схлопывания
python -m app.scripts.rebuild_word_groups

# 7. Озвучка: текст изменился — нужны новые клипы, старые становятся сиротами
python -m app.scripts.tts_synthesize
python -m app.scripts.tts_prune_orphans --delete
```

После шага 6 сверить прогресс — он обязан сохраниться до единицы:

```sql
SELECT SUM(times_shown), SUM(times_correct) FROM user_words;
-- ожидается 29691 и 26110
```

Порция в прогоне переводов по умолчанию 20 слов. Для записей, требующих
подробного разбора, это много: ответ упирается в предел вывода и возвращается
обрезанным JSON — 40 слов из 71 потерялись молча. В таких случаях `--chunk 6`.

Самая существенная — первая: она перепривязывает прогресс пользователей на
канонические слова и схлопывает дубли. На копии прода это 21 265 записей
прогресса, ни одна не потеряна: счётчики суммируются, «выучено» берётся по
логическому ИЛИ.

`audio_enabled` включается **всем существующим пользователям**. Это
намеренно: озвучку просили в отзывах, и патч без неё был бы невидим. Кому
мешает — выключит в настройках.

## 3. Сразу после заливки

**Пересобрать группы слов.** Обязательно: викторина отбирает слова по ним.

```bash
docker compose exec app python -m app.scripts.rebuild_word_groups
```

**Проверить, что викторина запускается.** Открыть бота, нажать «Учить слова»,
ответить на вопрос, дойти до разбора. Если звука нет — это не поломка,
см. шаг 4.

**Проверить сквозные сценарии машинно:**

```bash
docker compose exec app python -m app.scripts.verify_all_flows
```

Ожидается 82 шага и ни одной проблемы.

## 4. Озвучка: два шага, и они раздельные

Озвучка не нужна для работы бота. Он работает и без неё — карточка выходит
текстовой. Поэтому эти шаги можно делать после заливки, не спеша.

### 4.1. Перенести синтезированные клипы

Синтез уже сделан локально: **110 526 клипов, 1,71 ГБ** — все слова и все
примеры по шести языкам, включая польский. Тишина вокруг речи обрезана:
движок добавлял около полутора секунд, и у слова «zum» речь занимала 0,39
секунды из 1,87.

Осиротевшие клипы убраны — 23 409 файлов, 344 МБ. Ключ клипа это хеш
произносимого текста, поэтому исправленный перевод получает новый клип, а
прежний остаётся на диске. За правки базы такого накопилось 17% хранилища, и
всё это поехало бы по сети впустую.

**Перед переносом прогнать ещё раз**: с момента последнего синтеза база могла
измениться.

```bash
python -m app.scripts.tts_synthesize            # добрать недостающее
python -m app.scripts.tts_prune_orphans         # сначала посмотреть
python -m app.scripts.tts_prune_orphans --delete
```

Удаление безопасно: любой удалённый клип пересоздастся синтезом или при первом
показе карточки.

Копируется как есть:

```bash
# С машины разработчика
rsync -avz --progress tts/ user@server:/path/to/GenauLingua/tts/
```

Отдельно монтировать не нужно: в `docker-compose.yml` каталог проекта
смонтирован в контейнер целиком (`- .:/app`), поэтому `tts/` рядом с кодом
контейнер видит сразу.

Проверить, что доехало:

```bash
docker compose exec app python -m app.scripts.tts_synthesize --stats
```

### 4.2. Загрузить в Telegram и получить file_id

**Этот шаг обязательно боевым ботом.** `file_id` принадлежит конкретному
боту, и клипы, загруженные тестовым, боевой отправить не сможет.

```bash
docker compose exec app python -m app.scripts.tts_pregenerate \
  --lang de --all --delete-after
```

`--delete-after` отправляет клипы в чат админа и сразу удаляет: `file_id`
после удаления сообщения остаётся рабочим. Уведомления отключены, сообщения
живут меньше секунды. Около 2,5 часа на язык при темпе 3 клипа в секунду.

Прогон прерываемый: уже загруженное не переделывается. Можно гнать языки по
одному в удобное время.

**Без этого шага тоже работает.** Клип загрузится при первом показе слова:
первый человек ждёт лишнюю секунду, все следующие получают мгновенно.
Предгенерация только убирает эту секунду.

### 4.3. Если озвучка досинтезировалась после переноса

Синтез обрезает тишину сам — это часть записи клипа:

```bash
docker compose exec app python -m app.scripts.tts_synthesize     # добрать новое
```

Так было не всегда, и на этом я попался. Прежде обрезка стояла только в живом
пути `obtain_audio`, а массовый синтез писал клип как есть; первую волну
обрезал отдельный запуск, всё выглядело правильно — но каждый пересинтез
возвращал тишину, а запустить обрезку я забывал. Замер показал: у немецкого,
который почти не менялся, обрезано всё, а у польского не обрезано 65% клипов.
Поэтому обрезка перенесена в сам синтез: два пути расходиться не должны.

Отдельный прогон остаётся на всякий случай — для клипов, созданных прежним
кодом, и как сплошная проверка:

```bash
docker compose exec app python -m app.scripts.tts_trim_store --verify 40
docker compose exec app python -m app.scripts.tts_trim_store
```

Обрезка идемпотентна: уже обрезанные клипы она не трогает. Без этого свойства
каждый прогон срезал бы оставленный запас и постепенно съедал хвост слова.

Обрезка сама чистит кэш `file_id`: в Telegram лежали необрезанные клипы, и
оставить прежние file_id значило бы навсегда отдавать людям то, что только
что исправлено. **Флаг `--keep-cache` после настоящей обрезки передавать
нельзя** — я передал и получил 36 английских file_id, ведущих на старое
аудио. Он нужен только когда обрезка ничего не изменила.

## 5. Если что-то пошло не так

### Откат кода без отката базы

Новые колонки старому коду не мешают — он их просто не видит. Поэтому
сначала пробовать так:

```bash
git checkout main
docker compose build app && docker compose up -d app
```

Исключение: `user_words` получил язык в первичном ключе, и старый код о нём
не знает. Если викторина после такого отката ведёт себя странно — откатывать
и базу.

### Откат базы

```bash
docker compose exec app alembic downgrade <ревизия из шага 0>
```

Внимание: откат `d7e8f9a0b1c2` **не восстановит** разделение прогресса,
схлопнутое при схлопывании дублей. Для полного возврата — восстановление
из бэкапа:

```bash
gunzip -c ~/backup-....sql.gz | docker compose exec -T postgres \
  sh -c 'psql -U "$POSTGRES_USER" "$POSTGRES_DB"'
```

### Озвучка не играет

Проверить по порядку:

```bash
# Клипы на диске есть?
docker compose exec app python -m app.scripts.tts_synthesize --stats

# Что в кэше file_id и чьи они?
docker compose exec -T postgres sh -c \
  'psql -U "$POSTGRES_USER" "$POSTGRES_DB" \
   -c "SELECT bot_id, COUNT(*) FROM word_audio GROUP BY bot_id;"'
```

Если `bot_id` не совпадает с id боевого бота (цифры до двоеточия в токене) —
это клипы другого бота, они не заиграют. Бот сам их переделает при показе,
но можно и почистить:

```sql
DELETE FROM word_audio WHERE bot_id IS DISTINCT FROM <id боевого бота>;
```

## Чего в этой заливке нет

- **Польский как язык изучения.** Переводы заполнены на A1 и A2
  (2832 канонических слова), на B1 и выше — только те слова, которые попали в
  отдельные правки. Пока так, польский не входит в список доступных языков:
  ученик уровня B1 получил бы почти пустую викторину. Открывается одной
  строкой в `LEARNABLE_LANGS` после заполнения остальных уровней.
- **Переводы B1–C2.** Пересобраны только A1 и A2 — четверть базы, плюс
  отдельные слова с найденными дефектами. На остальных уровнях по-прежнему
  возможны перевёрнутые значения (найденный пример: `erreichbar` «доступен»
  переведено как «Недоступен»), переводы одним значением вместо всех и
  сломанная грамматика в турецком.

  Пакеты на B1 (157 запросов) и B2 (166 запросов) были отправлены и на момент
  записи шли уже девятый и пятый час при нуле готовых. Процесс, который их
  ожидал, завершился, и **никто их больше не опрашивает** — id сохранены в
  файлах `*.batch` рядом с предложениями, забирать через `collect_batch`.
  Пакет живёт 24 часа: если не забрать, результаты истекут.
- **Голоса кроме основного.** Предгенерирован один голос на язык. Если
  человек выберет другой (у немецкого их шесть), его клипы будут
  синтезироваться на ходу — по секунде на первое обращение к слову.

## Обновление README

README описывает бота как «только немецкий, развитие приостановлено». После
этой заливки это неверно: пять языков изучения, озвучка голосами носителей,
выбор голоса. Текст клиентский, и переписывать его — редакторское решение,
поэтому он оставлен как есть.
