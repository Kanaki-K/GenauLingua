
prune` (старые образы).

## 6. Словарь

```bash
scp wordbase.json.gz user@server:/path/to/GenauLingua/   # с машины разработчика
docker compose run --rm app python -m app.scripts.wordbase_transfer load --file wordbase.json.gz
docker compose run --rm app python -m app.scripts.wordbase_transfer load --file wordbase.json.gz --apply
docker compose run --rm app python -m app.scripts.rebuild_word_groups
```

Перенос **ничего не удаляет**: только UPDATE по номеру и INSERT новых.
Номер, который есть на проде и нет в файле, останавливает перенос целиком.
Суммы прогресса людей сверяются в той же транзакции. На репетиции:
изменено 12 902 слова (польский впервые, переводы, 666 форм приведены к
словарной: «kuck» → «gucken»), удалено 0.

## 7. Учёт и сверка

```bash
docker compose run --rm app python -m app.scripts.release_snapshot --out logs/after.json --compare logs/before.json
docker compose run --rm app python -m app.scripts.repair_accounting          # просмотр
docker compose run --rm app python -m app.scripts.repair_accounting --apply  # всегда: пересчёт месяца по источнику
docker compose run --rm app python -m app.scripts.audit_accounting
```

**Сверка — ДО починки.** `repair_accounting --apply` нарочно меняет баллы
текущего сезона (пересчёт по источнику), и после неё сверка показала бы
`≠` там, где ничего не потеряно. Сверка отвечает на вопрос «выкатка ничего
не потеряла», починка — «учёт верен»; это два разных шага.

`release_snapshot --compare` обязан закончиться «всё сохранено». Меняться
могут только `reminders_on` (всем включили) и число строк прогресса (дубли
схлопнулись) — суммы показов и верных обязаны совпасть. **Если `≠` хоть в
одной строке — НЕ ЗАПУСКАТЬ бота, перейти к «Откат».**

`repair_accounting` закрытые сезоны НЕ трогает без `--all-seasons`, и
трогать не надо: там розданы награды.

## 8. Запуск

```bash
docker compose up -d
docker compose logs -f app        # до строки «Run polling»
docker compose run --rm app python -m app.scripts.state_report
```

`up -d` пересоздаст и базу: у неё сменились порт (только 127.0.0.1) и
политика перезапуска. Это секунды, данные в томе. **Сейчас база прода
открыта в интернет** (`ports: "5432:5432"` — Docker обходит файрвол);
после `up -d` она слушает только 127.0.0.1. Проверить:
`ss -ltnp | grep 5432` — должно быть `127.0.0.1:5432`.

В каталоге проекта на сервере лежат `db_dump.sql`, `backup_20260307_190630.sql`
(дампы с данными людей) и `send_active.py`. Каталог смонтирован в контейнер
(`.:/app`). Решение владельца — перенести в `~/genaulingua-backups` (права
600) или удалить.

## Озвучка

Звук живёт в Telegram: однажды загруженный клип отдаётся по `file_id`
бесплатно и мгновенно. `file_id` принадлежит конкретному боту — клипы
тестового бота боевому не годятся.

Без всякой подготовки бот синтезирует клип при первом показе слова и
запоминает его `file_id`: первый человек ждёт ~1 с, остальные — нет.
Синтез с 14.10 снова надёжен (edge-tts 7.3.1, закреплена в `requirements.txt`;
на 7.3.0 — 0 отказов на 1 900 клипах),
но предзагрузка убирает и эту секунду:

```bash
docker compose run --rm app python -m app.scripts.tts_pregenerate --lang de --all
```

Для неё нужен приватный канал владельца (решение за ним) и каталог `tts/`
на сервере (3.8 ГБ, rsync) — это можно сделать и после выкатки.
