# === ИГРА ВСЛУХ: распознавание речи В РАНТАЙМЕ ===
#
# Эти три строки стояли в requirements-dev.txt с комментарием «боту не
# нужно» — верным в тот день, когда игры вслух ещё не было. Потом игра
# появилась, а строки остались в dev, и боевой образ собирался БЕЗ
# распознавателя.
#
# Чем это кончилось бы. `check_pronunciation` ловит любое исключение и
# возвращает `failed`, а `failed` по правилам проекта — «не разобрал», то
# есть НЕ ошибка ученика. Значит человек записывал бы голосовое, ждал и
# получал «не разобрал, попробуй ещё». Каждый раз. Молча, без единой
# записи в журнал об отсутствии библиотеки — потому что отсутствие
# библиотеки выглядит ровно как шум в микрофоне.
#
# Цена промаха выросла 13 октября, когда речь включили ВСЕМ: прежде это
# задело бы одного человека из 233, теперь — всех.
#
# Версии проверены сборкой образа, а не только локальным окружением, и это
# важно: локально стоит Python 3.13 и av 19, а образ на python:3.11-slim.
# `av==19` требует Python >= 3.12, то есть пин по локальным версиям ронял
# сборку с «No matching distribution found». Поймала это именно сборка —
# рассуждением такое не находится.
#
# Декодер mp3 в проекте СВОЙ (`mp3_trim.decode`), а не библиотечный
# `decode_audio` из faster-whisper, поэтому версия av для нас не
# принципиальна — важно лишь, чтобы она ставилась на 3.11 и умела читать
# mp3 и ogg/opus.
