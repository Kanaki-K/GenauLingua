## 0. Как вообще запускать

Без этого раздела ни одна команда ниже не заработает.

```bash
# Все скрипты — так. На Windows без PYTHONIOENCODING вывод рушится на кириллице
cd C:/Users/lodk9/PycharmProjects/GenauLingua
ENV_FILE=.env.local PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -u -m app.scripts.<имя>
```

- **Ключ API живёт в `.env.local`** (в gitignore через `.env.*`). Скриптам нужен
  `ENV_FILE=.env.local`, иначе `anthropic` не найдёт ключ и упадёт с
  «Could not resolve authentication method».
- **Ключ был вставлен в переписку и потому раскрыт** — после всех прогонов его
  надо сменить.
- **База — копия прода**, 233 пользователя, 12 902 слова. Правки едут **дампом
  таблицы `words`**, а не через git. Поэтому `git status` остаётся чистым, пока
  идёт работа над базой: это не значит, что ничего не сделано.
- **`app/scripts/*` в gitignore с белым списком.** Новый скрипт надо внести
  туда поимённо, иначе `git add` его молча не возьмёт. Я на этом спотыкался.
- **Строковые правки делать редактором, а не через оболочку.** Экранирование
  `\b` в регулярных выражениях ломалось трижды, и каждый раз проверка
  переставала работать молча.

### Ограничения, заданные владельцем

- **Бюджет.** Потрачено около $61. Сказано прямо: «второй раз пройтись по всем
  словам не выйдет». Поэтому порядок такой: сначала бесплатные проверки и
  правки кодом, платный прогон — один и последним.
- **Не ломать то, что работает.** Задачи сессии — польский, база, озвучка,
  карточка. Всё остальное менять только если это настоящий дефект, и говорить
  об этом.
- **Карточка показывает ОДНО слово на кнопке** — это решение владельца, принятое
  после сравнения трёх видов. Полный набор значений виден в разборе после
  ответа. Не «улучшать» обратно в перечисление: длинные кнопки он уже отверг.
- **Точка в конце слов и примеров не ставится** — так было до правок.
- Отчёты по-русски, без лишних извинений и самобичевания.

### Про «ноль готовых»

Это не признак поломки. Пакеты показывают 0 до самого конца и прыгают в готово
разом: B1 шёл 7 ч 44 мин, B2 — 3 ч 57 мин, и оба завершились с разницей в
минуту, хотя отправлены были с интервалом в четыре часа.

Проверено опытом: отправлен пробный пакет из **одного** запроса на 16 токенов
(`probe.batch`). Он тоже висел `in_progress` без результата, хотя квоту занять
не может. Значит задержка не связана ни с размером наших пакетов, ни с их
количеством — это общая задержка пакетной обработки. Документация обещает
«обычно в течение часа, до 24 часов».

Версия про очередь за выходной квотой аккаунта (каждый большой пакет
резервирует 1 254 000 токенов при квоте 2 000 000) **опровергнута** этим
опытом — пробный пакет резервировал 16 токенов и всё равно ждал.

**Подтверждение задним числом: `final_3` вернулся.** Создан 30.09 в 23:33 UTC,
завершён 01.10 в 09:20 UTC — **9 часов 47 минут** на три запроса. Забран, 27
предложений, содержимое просмотрено глазами: шесть языков, польский на месте,
`examples_ok` с разбором по языкам.

Это главный довод в пользу ожидания: очередь медленная, но живая, и из неё
выходят. Заодно это добивает версию про квоту с другой стороны — три запроса
ждали столько же, сколько сто четырнадцать, то есть размер ни при чём.

Что отсюда **не** следует: что большие пакеты уложатся в тот же срок. Девять с
половиной часов на три запроса говорят о заторе с фиксированной задержкой, но
проверить это можно только дождавшись. Большие созданы на 33 минуты **раньше**
малого — по логике очереди они уже на выходе.

### Как забрать

Сторож — **`app/scripts/watch_batches.py`**. Опрашивает раз в две минуты и
забирает сам, журнал в `watch4.log`. Компьютер для счёта не нужен — пакеты
считаются на серверах Anthropic; локально работает только опрос.

**Он перенесён в репозиторий из временной папки сессии.** Там он и жил, а такую
папку система может вычистить — тогда пакеты истекли бы вместе с оплатой, и
никто бы этого не заметил. Запуск:

    ENV_FILE=.env.local PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -u -m app.scripts.watch_batches

Запускать в фоне и перенаправлять вывод в файл.

**Сторож должен быть ровно один.** К утру 01.10 за теми же пакетами следили
пятеро: три процесса `propose --batch`, что их создали, и `watch_batches.py`.
Это уже дало дубль при сборе `final_3` — две побайтово одинаковые копии — и
грозило тем, что к шагу `apply` одни и те же предложения приедут дважды.
Лишние погашены, остался один. Гасить такие процессы безопасно: id пакета лежит
в `.batch`, а результаты ждут на стороне API.

Текущий сторож забирает в канонические `final_0.jsonl`, `final_1.jsonl`,
`final_2.jsonl` — те имена, что ждёт `finish_translation_round`, — пропускает
уже забранное, ведёт пробный пакет как датчик очереди и после сбора проверяет
себя: файл непуст, строки разбираются как JSON, иначе кричит «ТРЕВОГА».

Если сторож умер:

```bash
python -m app.scripts.collect_batch --list
python -m app.scripts.collect_batch msgbatch_01NdgbqUYLXQVBCYbQFLWFoc --kind words --out final_0.jsonl
# и так для остальных трёх
```

`collect_batch` забирает **и частичный результат**: отменённый или недоделанный
пакет не значит пустой. Так уже нашлись 50 оплаченных ответов, считавшихся
потерянными.

## 3. Что осталось сделать

### 3.1. Довести пакеты до базы

Порядок важен, он выведен из ошибок. Всю последовательность исполняет
`app/scripts/finish_translation_round.py`, но вот она по шагам:

```bash
# 1. Проверить предложения ДО применения — бесплатно
python -m app.scripts.validate_translations --files final_0.jsonl final_1.jsonl final_2.jsonl final_3.jsonl

# 2. Применить
python -m app.scripts.retranslate_wordbase apply --file final_0.jsonl
# и остальные три

# 3. Бесплатные правки, которые прогон ломает КАЖДЫЙ раз
python -m app.scripts.fix_turkish_i --apply        # латинская I вместо İ
python -m app.scripts.fix_uk_apostrophe --apply    # «мясо» вместо «м'ясо»

# 4. Примеры — ИЗ ДВУХ ИСТОЧНИКОВ
python -m app.scripts.example_quality --out defects.jsonl
python -m app.scripts.merge_defects --detector defects.jsonl \
    --model final_0_bad_examples.jsonl final_1_bad_examples.jsonl \
            final_2_bad_examples.jsonl final_3_bad_examples.jsonl \
    --out merged.jsonl
python -m app.scripts.fix_examples propose --in merged.jsonl   # ЕДИНСТВЕННЫЙ платный шаг, ~$1–2
python -m app.scripts.fix_examples apply --file example_fixes.jsonl

# 5. Записи, которые fix_examples ОТКЛОНИЛ, — это испорченные ПЕРЕВОДЫ,
#    а не примеры. Их надо пересобрать переводом
python -m app.scripts.retranslate_wordbase propose --ids <id из *_rejected.jsonl> --chunk 6

# 6. Группы: переводы входят в ключ схлопывания
python -m app.scripts.rebuild_word_groups

# 7. Озвучка
python -m app.scripts.tts_synthesize
python -m app.scripts.tts_prune_orphans --delete
```

ловят разное: на 719 парах пересечение составило 13. Прогон одного источника
пропускает примерно половину.

-- ожидается 29691 и 26110

## 7. Ловушки, каждая из которых стоила денег или времени

**Проверка, которая врёт, опаснее отсутствия проверки.** Поймал себя семь раз:
проверка искала не в том ключе и молча отвечала «чисто» на 1092 записях;
браковала безупречные `znajdować się` и `teslim etmek`; считала турецкий
аблатив `-den` немецким артиклем; видела немецкий артикль в английском «to die
of hunger»; ругалась на «DVD» в русской колонке; объявила дефектом 1704
исправных клипа; дважды приезжала с символом backspace вместо `\b` после правки
через оболочку. **Правило: смотреть на вывод, а не на число, и ставить скриптам
самопроверку перед работой.**

**Отменённый пакет не значит пустой.** Запросы, уже начатые, доводятся до конца
и списываются. Отмена стоила $1.20 и 50 готовых ответов, которые лежали на
сервере девять часов невостребованными.

**Устаревшие предложения затирают исправленное.** Из 1335 восстановленных 1142
оказались старше базы: дефект уже исправил другой прогон, а применение вернуло
бы старое. Перед применением сверять, есть ли дефект **сейчас**.

**Порция в 20 слов упирается в предел вывода** и теряет слова молча: 40 из 71.
На сложных записях ставить `--chunk 6`.

**Строковые правки — редактором, не через оболочку.** Экранирование `\b`
ломалось трижды, и каждый раз проверка переставала работать молча.

**Сначала читать запрос, потом платить.** Синхронный прогон C1/C2 шёл по
